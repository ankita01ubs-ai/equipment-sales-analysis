# equipment-sales-analysis

## Project Overview
This project analyses sales data to identify important sales trends, top/least performing products and other important business insights.

## Tools and Technologies
-Python
-Numpy
-Pandas
-Matplotlib
-Seaborn

## Dataset
Dataset contains sales related all information used to analyse the product performance, sales trends and other business metrics.

## Analysis Performed
-Data Cleaning
-Exploratory Data Analysis
-Product Performance Analysis
-Sales Trends Analysis
-Visualization

## Key Insights
-Three category performs almost near to each other whilst Lifting tops.
-Chain Pulley Block is the most profitable product 
-Delhi is the city where sales are highest.
